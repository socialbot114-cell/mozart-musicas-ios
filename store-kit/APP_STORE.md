## Descrição

Músicas para Estudar é uma curadoria offline de música clássica e brasileira para concentração, leitura e descanso.

Cada gravação publicada tem fonte, licença e território verificados. A experiência musical funciona sem internet, sem conta e sem anúncios.

Recursos:

- 50 gravações de domínio público com origem verificada.
- Seis coleções: Foco profundo, Piano para dormir, Piano para estudar, Clássica para leitura, Barroco e Música brasileira.
- Player imersivo com progresso e controles de reprodução.
- Mini-player persistente para retomar a qualquer momento.
- Contribuição avulsa e opcional de R$ 10 para apoiar o desenvolvimento, processada pela App Store.
- Timer de foco de 25, 50 e 90 minutos.
- Capas editoriais e biblioteca pesquisável.
- Layout próprio para iPad com barra lateral.

Não é necessário criar uma conta. O conteúdo musical funciona offline. O app não exibe anúncios nem coleta dados pessoais; uma conexão é necessária para compras opcionais processadas pela App Store.

## Notas de revisão

Olá,

O Músicas para Estudar é um reprodutor de música clássica totalmente offline para foco e estudo.

Para testar:

1. Abra o app.
2. Na aba Início, toque no destaque "Foco profundo" ou em uma coleção em "Momentos".
3. Toque em uma obra para abrir o player.
4. Use os controles de reprodução e o progresso.
5. Abra a aba Explorar para buscar e filtrar por categoria.
6. Abra a aba Foco para usar o timer.
7. Em Biblioteca, veja a opção de contribuição avulsa e opcional para apoiar o app. O preço é exibido pela App Store.

Não é necessário criar conta ou conceder permissões. A música funciona offline; a contribuição opcional é processada pela App Store e requer conexão. Não há anúncios, rastreamento ou conteúdo que exija autenticação. As gravações são de domínio público com origem verificada.

Obrigado.
